# team-efsrt-pro
Portal académico SOFT-EFSRT para registrar horas, evaluar avances y emitir reportes de prácticas estudiantiles. Proyecto del equipo team-efsrt-pro.
## 🛠️ Tecnologías utilizadas
- **HTML5** — Estructura del sitio web
- **CSS3** — Diseño y estilos visuales
- **JavaScript** — Interactividad y animaciones
- **Python** — Lógica del lado del servidor
- **MySQL** — Almacenamiento de datos
- **Git / GitHub** — Control de versiones
